# JavaScript DOM Project

This project contains the two required exercises:

- `exo_parcours_DOM.html` and `script_parcours_DOM.js` navigate the DOM and display the seven answers in the console.
- `exo_modif_DOM.html` and `script_modif_DOM.js` apply the eight required modifications.

## How to Run

Open each HTML file in a browser. For the first exercise, open the developer tools and select the **Console** tab to see the answers.

The second page uses the structure of the Bootstrap 4 “Album” example shown in the assignment. Bootstrap 4 is intentionally retained because the exercise relies on classes such as `jumbotron`, which are not available in Bootstrap 5.
